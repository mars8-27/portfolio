# Abhiramsai Mamidala (`@mars8-27`) — Portfolio

Interactive AI & Backend Engineering portfolio built with **React**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deploy to Vercel

1. Push to `github.com/mars8-27/portfolio`.
2. Vercel automatically runs `npm run build` and deploys `dist/`.
